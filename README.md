# Congo International Logistics SARL — Website

Marketing website for **Congo International Logistics SARL**, a shipping, freight and cargo company based in Kinshasa, DRC.

Built by [Anchor Noir Studios](https://www.anchornoirstudios.co.za/).

## Features

- English / French language switch
- Services: sea freight, air freight, road transport, customs clearance, warehousing, project & mining cargo
- Shipment tracking request and quote form (sent via WhatsApp or email)
- Cargo volume (CBM) and chargeable-weight calculator
- FAQ, contact details and map
- Mobile-friendly layout with a quick-action bar (Call · WhatsApp · Quote)

## Structure

| File | Purpose |
| --- | --- |
| `index.html` | Page content |
| `styles.css` | Base layout and design |
| `interactive.css` | Animations and interactive components |
| `mobile.css` | Phone and tablet refinements |
| `script.js` | Translations, forms, calculator, scroll effects |
| `images/logo.jpg` | Company logo |

## Running locally

It's a static site with no build step. Open `index.html` in a browser, or serve the folder:

```bash
npx http-server -p 5173
```

## Deploying

Upload the files to any static host (Netlify, Vercel, GitHub Pages, or regular web hosting).
